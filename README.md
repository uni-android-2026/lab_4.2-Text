# Практическая работа №4.2

## Описание
В рамках работы создан экран с большим объёмом текста и изображением, для просмотра которого требуется вертикальная прокрутка.

## Что было сделано
1. В основу экрана добавлен `ScrollView`, чтобы длинный контент не обрезался по высоте.
2. Внутри него размещён вертикальный `LinearLayout` с картинкой и текстом.
3. Иллюстрация подключена через `ImageView` и выводится в режиме `centerCrop`.
4. Основной текст перенесён в строковый ресурс и оформлен с помощью HTML-тегов форматирования.
5. Размер шрифта и структура разметки настроены так, чтобы текст читался как единый блок.

## Результат
В результате получился прокручиваемый экран, который закрепляет работу со `ScrollView`, ресурсами строк и форматированным текстом.
